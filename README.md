# Omarchy configuration

Personal Omarchy shell configuration and custom plugins.

## Restore

Copy the contents of `config/omarchy/` into `~/.config/omarchy/`, then restart
the shell with:

```sh
omarchy restart shell
```

Included custom plugins:

- `louis.mouse-dpi`
- `louis.logitech-battery`

The third-party `slcode777.omagotchi` plugin is intentionally not vendored.
